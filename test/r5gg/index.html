Важно в этой сборке

Блок FLdigi выключен по умолчанию. Он больше не обращается к FLdigi, пока вы не включите его в ⚙ → CAT галочкой «Блок FLdigi над журналом». Выключен — программа вообще не трогает FLdigi, и он не закрывается.

CW-питч — там же, в ⚙ → CAT: поле 500/600/700/800. Поставьте своё, и частота сойдётся.

Что исправлено с прошлой сборки

  • FLdigi закрывался через несколько минут. Причина в соединении: программа держала его открытым между запросами, а FLdigi этого не переживает. Теперь на каждый запрос отдельное соединение, которое сразу закрывается.
  • FLdigi не закрывается. Блок «что слышит FLdigi» опрашивал его девять раз каждые 1,5 секунды — FLdigi такого темпа не держал. Теперь четыре вопроса раз в 3 секунды, текст и поля лога — раз в 5 секунд, после отказа — пауза минута.
  • Сохранение связи быстрее. После записи журнал перерисовывался дважды — второй раз через 1,4 секунды ради подсветки новой строки. Теперь подсветка снимается точечно. В отладочном журнале появился замер: [qso] save took N ms, drawing M ms.
  • FLdigi: частота мышкой. Hamlib на Windows с русской локалью присылает частоту с запятой — F 7175000,000000. Программа её не понимала и отвечала отказом, поэтому частота «прыгала и возвращалась». Теперь принимается и точка, и запятая.
  • Фото в журнале: значок камеры у связи, у которой фото уже скачано; нажатие открывает фото. Заглушки справочника (чёрный прямоугольник) больше не считаются фото.
  • Дипломы: рядом с подтверждённым числом — «сработано».
  • Заметки в карточке связи подставляются из прошлой связи с этим позывным.
  • Страна для дробных позывных (VP8/G, 3Y0) — верная.

Что проверить

  1. FLdigi и частота. Настройки FLdigi → Rig control → Hamlib: галочка Use Hamlib, Rig — Hamlib NET rigctl (Stable), Device — 127.0.0.1:4532. В Rig control нажмите на частоту и покрутите колесо или введите число — трансивер должен перестроиться и остаться на новой частоте.
  2. Вид излучения из FLdigi — переключается (это работало и раньше).
  3. PTT из FLdigi.
  4. Фото: в журнале появился значок камеры — нажмите, фото должно открыться.

Если что-то не так — пришлите отладочный журнал: ⚙ → внизу «Журнал отладки» → отправить. По нему видно каждую команду и ответ.

Эта сборка — только для проверки. Когда всё заработает, правки войдут в общий выпуск, и обновляться можно будет кнопкой в программе.
