Отправка связей в журнал QRZ.com прямо из программы — как в Nexus

Скачать R2FEL-LOG-Setup-1.0.108-r3did.1.exe
Windows 10 и 11, 64 бита
Для Windows 7, 8 и 8.1: тот же установщик для старых Windows.
Пробная сборка. Обычная программа и её настройки не затрагиваются: журнал остаётся на месте.
Нужна подписка QRZ.com (XML, как у вас). Без неё прямая отправка не работает — остаётся файл, как раньше. Ключ API берётся на qrz.com: Logbook → Settings → API Key.
  1. Скачайте и установите файл выше. Если Windows пишет «Система защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае» (программа не подписана платным сертификатом).
  2. Запустите R2FEL HamLog и откройте ⚙ Настройки → QRZ.com.
  3. В строке «Ключ API журнала» вставьте ключ из своего журнала на qrz.com и нажмите «Сохранить ключ». Под полем появится «Ключ сохранён (…XXXX)».
  4. Включите «Отправлять сразу после связи» — тогда каждая новая связь уходит в QRZ.com сама. Или оставьте выключенным и жмите «Отправить всё» вручную. Старые связи программа не трогает: уходят только те, что записаны после сохранения ключа.
  5. Проведите одну связь (можно с JTDX — связь запишется сама) и посмотрите на qrz.com, появилась ли она в журнале. В программе у неё должна появиться отметка Q.
Если что-то не так — под кнопкой будет написано словами, что ответил сайт (например «invalid api key»). Пришлите мне этот текст и скажите, отправлять сразу после связи или кнопкой. Если связи не появились на qrz.com — тоже напишите: значит, сайт принял не так, как я думал, и я поправлю.

Проверять придётся вам — у меня подписки QRZ.com нет. Спасибо за помощь! — Алексей, R2FEL
