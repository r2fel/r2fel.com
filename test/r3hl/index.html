ТЕСТ 1.0.113

Сборка для R3HL

Индивидуальная: после проверки удалю её и это войдёт в основную версию на сайте

R2FEL-LOG-Setup-1.0.113.exe

Для Windows 7, 8, 8.1 — другой установщик, для старой Windows

Ставится поверх, журнал и настройки остаются на месте.
Что исправлено:
  1. Переключение диапазонов. После смены частоты программа проверяла результат командой, которую FT-1000MP не понимает (это формат других трансиверов), поэтому потерянная команда оставалась потерянной. Теперь программа читает собственный блок состояния радио и, если оно не перестроилось, повторяет команду.
  2. HRDLog вернулся. ⚙ → HRDLog: позывной и код выгрузки из письма HRDLog (это не пароль от сайта). Связи уходят по одной, «уже есть» считается отправленным.
  3. Подсказки на страницах служб: где взять токен, код или ключ — по шагам, прямо на странице.
  1. Поставьте сборку поверх.
  2. Диапазоны: пощёлкайте по ним туда-сюда несколько раз подряд, в том числе быстро. Пропусков быть не должно.
  3. HRDLog: ⚙ → HRDLog, впишите позывной и код, сохраните, отправьте пару связей.
  4. Посмотрите подсказки на страницах служб — понятно ли написано.
Если что-то не так — ⚙ → «Журнал отладки» → «Сохранить копию» и пришлите файл. Если кнопка «Отправить разработчику» сработает, хватит и её.

Спасибо за отчёты — по вашему архиву нашлась та проверка частоты.
