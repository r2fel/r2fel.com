Реклама при запуске

Заставка, которую видят все при открытии программы (компьютер) и приложения (телефон). У телефона и компьютера она своя: у каждого свой ролик и своё включение. Эту страницу видите только вы: без вашего ключа в ней ничего нельзя изменить.

Вход

Где взять ключ (один раз)
  1. Зайдите на github.com под своим именем r2fel.
  2. Справа вверху ваш значок → Settings → внизу слева Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Название: «R2FEL реклама». Срок: 1 год.
  4. Repository access → Only select repositories → r2fel/r2fel.com.
  5. Permissions → Repository permissions → Contents: Read and write (больше ничего не нужно).
  6. Нажмите Generate token, скопируйте длинный ключ и вставьте сюда. Потом его уже не показать — сохраните у себя.

Ключ работает только для этого сайта и только с файлами. Потеряли или кому-то показали — удалите его там же и создайте новый.
